# Architecture Decision Records

ADRs are the authoritative history for decisions that materially affect architecture or implementation.

## Naming

`ADR-NNN-short-title.md`

## Lifecycle

Proposed → Accepted → Superseded/Deprecated

Historical ADR meaning must not be silently rewritten. A changed decision creates or updates the decision record with explicit migration impact.
